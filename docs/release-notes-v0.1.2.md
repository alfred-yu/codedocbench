## CodeDocBench v0.1.2

C/C++ 项目代码文档生成工具，面向 DO-178C 追溯场景。把源码目录树、低层需求（LLR）与文档生成串成一条五步流程，最后导出可直接导入追溯系统的链接文件。

### 安装包

| 格式 | 文件 | 说明 |
| --- | --- | --- |
| MSI | `CodeDocBench_0.1.2_x64_en-US.msi` | 企业批量部署 |
| NSIS | `CodeDocBench_0.1.2_x64-setup.exe` | 交互式安装 |

Python 后端已用 PyInstaller 冻结为 `backend.exe` 内嵌在安装包中，**目标机器无需安装 Python**。

### 本版要点

- **解析器 v1.3.0 口径收紧**：函数章仅输出函数定义；`#define` 归入宏章、`const` 全局变量归入常量章。相应地 Object Type 只有「全局变量定义」与「函数定义」两章的数据行记为 `Source Code`，其余记为 `Comment`，文档生成与一致性校验两侧口径一致。
- **一致性校验报告改为导出 Excel**：三个 sheet（校验汇总 / 代码侧 SourceCode 明细 / 需求侧一致性明细），汇总页内嵌 Canvas 绘制的图表，未被追溯的空 Parent ID 行与未被引用的需求行整行浅红标出。
- **链接文件生成结果自动失效**：链接行依赖「文档目录树 + 源码解析结果 + 低层需求数据」三者，任一变化时上次结果立即作废并给出具体原因，杜绝静默导出过期数据。
- 步骤 5 链接文件生成补齐：链入 / 链出信息配置、预览、超过 50 行自动分片、预览按导出文件分页。

### 已知限制
