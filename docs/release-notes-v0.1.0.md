## CodeDocBench v0.1.0

首个正式发布版本。C/C++ 项目代码文档生成工具，面向 DO-178C 追溯场景，把源码目录树、低层需求（LLR）与文档生成串成一条五步流程。

### 安装包

| 格式 | 文件 | 说明 |
| --- | --- | --- |
| MSI | `CodeDocBench_0.1.0_x64_en-US.msi` | 企业批量部署 |
| NSIS | `CodeDocBench_0.1.0_x64-setup.exe` | 交互式安装 |

### 本版要点

- 五步向导：打开解析项目 → 构建文档目录树 → 关联低层需求 → 生成文档 → 生成链接文件。
- **低层需求关联随项目持久化**：所选 Excel 路径与列映射记录在项目目录的 `.codedocbench.json` 中，随项目移动、换机不丢失。
- 解析器覆盖 C/C++ 的 include、宏、常量、typedef、函数、结构体、枚举、全局变量，输出按文档章节组织。

### 升级提示

后续版本（v0.1.2）调整了解析器口径：函数章仅输出函数定义，`#define` 归宏章、`const` 全局变量归常量章。若你的追溯文档依赖 v0.1.0 的旧章节口径，升级前请先确认。

建议直接使用 [v0.1.2](https://github.com/alfred-yu/codedocbench/releases/tag/v0.1.2)。
